# Lead Service Line Replacement Programs in 28 U.S. Cities, 2026 (LeadPipeHelp)

This dataset covers how 28 U.S. city water utilities handle replacement of lead service lines on private property: free, partly paid or paid by the homeowner, with the cost, the address lookup and the official source for each city.

Published by LeadPipeHelp (https://leadpipehelp.org/), an independent public resource run by Willow Creek Group LLC, St. Clairsville, Ohio. It is not a government agency.

## How it was made

Each row was checked individually against official sources only: state Medicaid, aging, utility commission and water utility pages, statutes, administrative code and federal agency pages. Every fact carries its official source and the date it was checked. Where an official page does not state something, the dataset says so (for example "Not confirmed" or "Unknown") rather than guessing.

Rules change. Check the official source in each row before relying on a value.

## Files

### lead-service-line-programs-2026.csv

One row per city: the utility and program, whether the city pays for the private side, the cost to the homeowner, the official address lookup, phone, deadline or pace, the state loan fund figure with its source, the official program source and the date checked.

29 rows. Columns:

- `city`
- `state`
- `group`
- `utility`
- `program`
- `city_pays_private_side`
- `cost_to_homeowner`
- `address_lookup`
- `phone`
- `deadline_or_pace`
- `state_loan_fund_figure`
- `state_loan_fund_source`
- `state_loan_fund_checked`
- `official_source`
- `date_checked`
- `verification`
